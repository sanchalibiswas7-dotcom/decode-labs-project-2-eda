# Project 2 - Exploratory Data Analysis (EDA)

This project was completed as part of my **Data Analytics Internship at DecodeLabs**.

## Project Objective

The objective of this project was to perform Exploratory Data Analysis (EDA) on a cleaned E-commerce dataset to identify patterns, trends, correlations, and business insights using Python.

## Analysis Performed

* Descriptive statistical analysis
* Product sales analysis
* Revenue analysis
* Payment method analysis
* Monthly sales trend analysis
* Correlation analysis
* Outlier detection
* Data visualization using charts and graphs

## Dataset Description

The dataset contains E-commerce order information including:

* Order details
* Product categories
* Quantity and pricing
* Payment methods
* Order status
* Customer-related information

## Key Insights

* Certain products generated higher sales and revenue compared to others.
* Credit Card was one of the most frequently used payment methods.
* Monthly sales analysis showed variations in revenue across different months.
* Correlation analysis indicated that TotalPrice was strongly influenced by Quantity and UnitPrice.
* Outlier detection helped identify unusually high-value orders in the dataset.
